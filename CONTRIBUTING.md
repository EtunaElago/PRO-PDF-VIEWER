# Contributing to PRO PDF Viewer

We love your input! We want to make contributing to PRO PDF Viewer as easy and transparent as possible.

## Development Process

1. Fork the repo and create your branch from `main`
2. Make your changes
3. Add or update tests as needed
4. Ensure the test suite passes
5. Make sure your code lints
6. Issue that pull request!

## Pull Request Process

1. Update the README.md with details of changes if applicable
2. Update the CHANGELOG.md following Keep a Changelog standards
3. The PR will be merged once you have the sign-off of at least one maintainer

## Code Style

- Follow Kotlin coding conventions
- Use 4-space indentation
- Use descriptive variable names
- Add comments for complex logic
- Write unit tests for new features

## Setting Up Development Environment

1. Clone your forked repository
2. Open in Android Studio
3. Set up signing config for release builds
4. Add `google-services.json` for Firebase
5. Build and run!

## Reporting Bugs

Use the GitHub Issues tracker with the bug report template.

## Suggesting Enhancements

Use the GitHub Issues tracker with the feature request template.
