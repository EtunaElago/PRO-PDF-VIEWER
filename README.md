# PRO PDF Viewer 📄

A professional PDF viewer and management app for Android with powerful features and Material Design.

![GitHub](https://img.shields.io/github/license//PRO-PDF-Viewer)
![GitHub release](https://img.shields.io/github/etunaelago/release/etunaelago/PRO-PDF-Viewer)
![GitHub Workflow Status](https://img.shields.io/github/actions/workflow/status/etunaelago/PRO-PDF-Viewer/android-ci.yml)

## Features ✨

- 📁 **File Management** - Organize PDFs in folders and subfolders
- 🔍 **Smart Search** - Search within PDF documents
- 🎨 **Material Design** - Beautiful, modern UI with dark/light themes
- 📱 **Recent Files** - Quick access to recently opened documents
- 🗂️ **Folder Organization** - Create, rename, and manage folders
- 🚀 **Fast Performance** - Optimized for smooth PDF rendering
- 📊 **Analytics** - Usage tracking and crash reporting
- 🔒 **Privacy Focused** - Your documents stay on your device
